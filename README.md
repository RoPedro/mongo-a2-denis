# INSTRUÇÕES PARA RODAR O PROJETO LOCALMENTE

1. Criar um container Docker do Mongo usando a [imagem oficial do mongo](https://hub.docker.com/_/mongo/) (8.2.2-noble), mapeando a porta 27017:27017
2. Rodar `pip install -r requirements.txt` (criar um virtual environment é recomendado)
3. `python/python3 analisedengue.py`
